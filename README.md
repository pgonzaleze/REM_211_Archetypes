# System Archetypes: Flashcards and Practice

An interactive study tool for learning the eight classic system archetypes from systems thinking. It runs in any web browser, with nothing to install and no login.

**Live site:** (https://pgonzaleze.github.io/REM_211_Archetypes/)

Built for the course *REM 221 - FALL 2026* at *SFU*.

## The eight archetypes

1. Eroding / Drifting Goals
2. Escalation
3. Fixes that Fail
4. Shifting the Burden
5. Limits to Success
6. Growth and Underinvestment
7. Success to the Successful
8. Tragedy of the Commons

## What's in the app

| Tab | What you do |
|---|---|
| **Flashcards** | Flip through cards showing the definition, feedback loop, environmental example and way out. Mark cards as "I know this" or "Review again", and choose to see the name or the behaviour first. |
| **Match** | Pair eight descriptions with the right archetype and check your answers. |
| **Quiz** | Answer ten randomised questions. At the end you see which archetypes to review. |
| **Compare** | Read side-by-side explanations of the pairs students confuse most, such as Fixes that Fail vs Shifting the Burden. |

## How to use it (students)

1. Open the live site link above.
2. Start with **Flashcards**. Try to say the definition, the loop and the way out before you flip each card.
3. Use **Match** and **Quiz** to test yourself. Repeat the quiz until you stop missing archetypes.
4. Use **Compare** when two archetypes feel alike.

Progress is not saved between visits. Refreshing the page starts you over.
